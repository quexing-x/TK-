Data deletion instructions

移除授權，
刪除本機資料。

你可以在本機刪除 TK Ads Automation 保存的 Meta 接入資料，並在 Meta 平台撤銷本應用授權。兩個步驟互相獨立，建議依序完成。

1. 刪除本機保存資料

  1. 開啟 TK Ads Automation，進入「Meta 接入」。
  2. 先關閉帳戶自動化與 Meta 平台開關。
  3. 刪除該廣告帳戶，或刪除共享憑證 Profile 中的 App Secret 與 Access Token。
  4. 完成後，本機不再保留該接入憑證；刪除帳戶時，其同步資料、建立任務與操作紀錄會依產品刪除流程一併移除。

2. 在 Meta 撤銷應用授權

  1. 登入 Facebook，開啟「設定和隱私」→「設定」。
  2. 進入「商業整合」或「應用程式和網站」。
  3. 找到 TK Ads Automation，選擇「移除」。
  4. 如 Meta 顯示刪除相關資料的選項，請一併勾選並確認。

3. 提交人工刪除請求

如果你無法操作原本的 Windows 裝置，或需要確認與 Meta App ID 1570051734766701 相關的資料處理狀態，請寄送電子郵件。請提供廣告帳戶 ID 或 Page ID，不要在郵件中提供 Access Token、App Secret 或 Facebook 密碼。

寄送資料刪除請求
收到可驗證的請求後，我們會在 30 天內完成處理或回覆所需的身分與資產權限驗證資訊。

4. 刪除結果

刪除完成後，本應用無法繼續讀取或管理已撤銷的 Meta 資產。Meta 自身保存的資料與刪除期限由 Meta 的政策與法定義務決定。
