Privacy policy · Meta integration

廣告資料留在
你的控制範圍內。

本政策說明 TK Ads Automation 如何透過 Meta Marketing API 存取你授權的廣告資產，以及資料如何在你的 Windows 裝置上被使用、保護與刪除。

01 · AUTHORIZE由你授權 Meta 資產僅存取你選擇的廣告帳戶與粉絲專頁。
02 · PROCESS在本機執行規則報表、規則判斷與操作紀錄保存在本機資料庫。
03 · CONTROL隨時停用或刪除你可移除憑證、帳戶資料與 Meta 應用授權。

1. 適用範圍

本政策適用於 TK Ads Automation（以下稱「本應用」）中的 Meta 廣告帳戶接入、只讀同步、規則引擎、廣告狀態啟停與 PAUSED 廣告建立功能。

本應用僅供獲得相關廣告資產授權的使用者管理其自有或獲授權的 Meta 商業資產。

2. 我們處理的資料

  • 帳戶與資產識別資料：Meta App ID、Business Portfolio ID（如有）、廣告帳戶 ID、粉絲專頁 ID，以及 Campaign、Ad Set、Creative、Ad 的識別碼與名稱。
  • 廣告成效資料：狀態、花費、曝光、點擊、轉換、加購及由 Meta Marketing API 回傳的相關洞察指標。
  • 授權資料：使用者提供的 Access Token、App Secret，以及執行粉絲專頁廣告所需的 Page Access Token。Page Access Token 僅在請求期間使用，不另行持久保存。
  • 本機操作資料：連線檢測、同步結果、規則決策、啟停結果、建立任務與稽核紀錄。
不處理的資料：本應用不要求 Facebook 密碼，不讀取私人訊息，不出售個人資料，也不以廣告資料建立跨服務使用者画像。

3. 使用目的

  • 驗證使用者是否有權存取指定的 Meta 廣告帳戶與粉絲專頁。
  • 顯示 Campaign、Ad Set 與 Ad 的狀態及成效。
  • 依使用者設定的獨立 Meta 規則產生預覽或執行啟停操作。
  • 在使用者主動操作時建立初始狀態為 PAUSED 的廣告物件。
  • 保存必要的本機稽核紀錄，以協助檢查錯誤與避免重複寫入。

4. 儲存、安全與保存期限

App Secret 與 Access Token 透過 Windows Data Protection API（DPAPI）加密後保存在使用者裝置。廣告資料與操作紀錄保存在本機 SQLite 資料庫。本應用營運者不建置用於集中收集這些資料的雲端資料庫。

資料會保存至使用者刪除廣告帳戶、共享憑證 Profile 或本機應用資料為止。使用者也可在 Meta 設定中撤銷本應用的存取權。

5. 分享與第三方服務

本應用不出售或出租資料。資料僅在執行使用者要求的功能時傳送至 Meta Platform。Meta 對其平台上的資料處理受其自身條款與政策約束。

若法律要求或為保護使用者、平台與公眾的合法權益，本應用營運者可能在必要範圍內保存或揭露相關紀錄。

6. 使用者權利與資料刪除

你可以查看、停用、撤銷或刪除本應用保存的 Meta 接入資料。完整步驟請參閱資料刪除說明。
