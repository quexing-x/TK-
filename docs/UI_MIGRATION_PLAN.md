# 前端 UI 迁移计划

## 目标结构

- `apps/web/src/ui/index.css`：唯一样式入口。
- `apps/web/src/ui/system.css`：双主题 Tokens、布局、组件、状态、响应式与动效的权威实现。
- `apps/web/src/ui/structure.css`：承载现有业务组件稳定的结构 class 契约，不定义视觉方向。
- 页面组件继续复用现有 API、权限与业务状态；展示层通过现有 class 契约迁移到新系统。

## 阶段

1. 设计系统、应用外壳、导航与公共组件。
2. 总览/账户、自动化/规则。
3. 广告管理、创建广告。
4. 分析/任务、接入/通知/手册。
5. 系统用户/运维、弹窗/表单/状态统一。
6. 清理确认无引用的旧样式并执行完整回归。

每阶段最多两轮只读 Reviewer 审查；第二轮后非阻塞问题记录为债务继续。未经授权不提交、不推送、不创建 PR。
