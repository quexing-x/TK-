# 前端 UI 重构功能契约

本清单冻结 UI 重构前的用户可见能力与前端业务边界。重构只改变呈现层，不改变请求参数、响应处理、权限、状态管理、轮询和用户操作结果。

## 路由与应用外壳

- 保留 `#overview`、`#automation`、`#ads`、`#analytics`、`#rules`、`#notifications`、`#launch`、`#tasks`、`#system-users`、`#maintenance`、`#manual`。
- 旧书签 `#users` 继续重定向到含账户管理的总览页。
- 保留登录初始化、账户选择与本地记忆、浅深主题与本地记忆、30 秒 bootstrap 刷新、系统运行开关、Hash 导航和 `Ctrl/Cmd+K` 命令菜单。
- `users:manage` 与 `system:control` 等既有权限继续控制入口、操作与禁用提示。

## 页面能力

| 页面 | 必须保持的能力 |
|---|---|
| 总览与账户 | 运行指标、连接健康、异常、待处理、事件流、快捷创建；账户增删改、连接配置、能力检测、只读同步、自动化开关；账户显式区分 TikTok / Meta，Meta 离线账户不进入连接健康和自动化统计 |
| 自动化 | 预览/运行、决策、审批、运行记录、写入熔断状态与复位；只显示可运行的 TikTok 账户 |
| 广告管理 | 单/全部账户、搜索筛选、分页、状态确认、人工接管与恢复、一次性/跨夜计划及取消、本地刷新；Meta 离线账户不可进入 |
| 广告分析 | 账户与日期范围、层级筛选、指标摘要、批次趋势；Meta 离线账户不可进入 |
| 规则配置 | 九类全局规则、数值步进/滑块、适用层级、保存 |
| 消息推送 | 邮件、企业微信、飞书配置，测试发送与历史 |
| 创建广告 | 单账户、多账户、复制；账户就绪、预设 CRUD、高级映射、Excel/CSV 导入校验、差异预览、同系列草稿批次同步发布、不同系列有限并发、队列/立即执行、进度、失败重试、取消；Meta 离线账户不可作为来源或目标 |
| 任务中心 | 筛选、历史、详情、尝试记录、重试、取消；广告启停结果核验 |
| 系统用户 | 用户、角色、权限、启停、创建、修改密码与校验 |
| 运维 | 版本/更新安全状态、备份、恢复确认、审计日志 |
| 操作手册与接入 | 搜索/章节；TikTok Cookie/Official API、cURL 导入；Meta 共享 App 档案、可选 BM、广告账户发现/绑定、连接检测、能力及同步质量 |

## Meta 离线隔离契约

- `meta-offline` 只代表内部架构占位，不是 TikTok `official-api` 的别名；它必须保持零凭据、零能力、零网络并在本地失败。
- `meta-marketing-api` 是独立 Provider：共享 Access Profile 的 App ID 唯一，App Secret + Token 为单一加密包，BM 可选；广告账户只引用 Profile。
- Meta 真实自动写入必须同时满足系统总开关、Meta 运行开关、账户开关、`automation-status`、授权能力与 Campaign/Ad Set/Ad allowlist；任何一层关闭都不得调度。
- Meta 账户只进入 Meta 资产、Meta 规则与 Meta 接入页面，不得进入 TikTok 创建、复制、申诉、删除或 TikTok 规则引擎。
- 侧栏隔离预览必须使用内存数据库、Fixture 密钥、无 Transport Provider 和 `startScheduler:false`；浏览器回归不得触发真实 Meta 请求。

## 横切契约

- `api.ts` 及现有业务辅助模块是唯一请求与业务转换来源，UI 不复制业务逻辑。
- 保持加载、空、错误、无权限、禁用、确认、成功和失败状态。
- 保持表单字段含义、校验条件、按钮回调、后台任务和轮询周期。
- 浏览器回归不得触发真实 TikTok 或 Meta 写操作。
