# TK Automation 中文品牌基线

## 品牌人格
精准 / 稳定 / 高效 / 专业 / 可控

## Logo
“TK”置于控制框内，K 的斜线延伸为操作路径，末端以节点表示可监控、可追踪、可执行。适用于 Windows 应用图标、顶部栏、账户状态、批量任务和导出文件。

## 品牌标语
**大规模投放，也要稳稳掌控。**

## 主色
`#2856D8` 钴蓝：导航、主按钮、选中状态、执行路径。

## 辅助色
`#168A57` 信号绿：账户健康、连接正常、执行完成。

## 状态色
警告琥珀 `#C47A12` · 错误红 `#C2413B` · 信息蓝 `#3B82C4`

## 中性色
炭黑 `#111827` · 石板灰 `#1F2937` · 雾灰 `#F3F5F7`

## 字体方向
中文界面优先使用思源黑体 / Microsoft YaHei UI；账户 ID、广告 ID、预算、ROAS 和命令信息使用 Fira Code 或等宽字体。正文不低于 13px，数字使用等宽数字对齐。

## 图标风格
统一细线图标，1.5–2px 描边，圆角端点。图标只表达操作：控制、筛选、同步、暂停、告警、导出、表格、状态。禁止 emoji 和装饰性图标。

## 视觉元素
控制框、单一路径、状态节点、测量线、细分隔线、状态标签、批量操作栏、账户能力轨道。

## 品牌图形
“操作轨道”是核心图形：从账户输入，经连接、同步、规则判断，最终到批量执行。所有状态都沿这条轨道表达，不使用无意义的光效。

## 质感
深炭黑、钢铁灰和雾白的克制组合；轻微纸张颗粒、工程构造线和精确对齐。高级感来自秩序、留白和反馈速度。

## 图片风格
中国跨境电商运营者的真实工作环境：夜间工作台、显示器、投放计划、数据表格、纸面标注。画面安静、专注、可信，不出现摆拍人物或泛化办公室。

## 品牌禁区
赛博朋克、廉价霓虹、紫蓝 AI 渐变、过度发光、玻璃拟态、随机科技纹理、卡片套卡片、无意义英文长句、平台 Logo 仿制、过度营销话术。
